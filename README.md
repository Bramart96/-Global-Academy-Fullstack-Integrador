# Global Fullstack

Plataforma web orientada a conectar desarrolladores y servicios digitales.

Los usuarios pueden:
- publicar servicios
- filtrar desarrolladores por país
- buscar por conocimientos y tecnologías
- explorar perfiles de desarrollo

## Tecnologías utilizadas

- JavaScript
- React
- Node.js
- Tailwind CSS
- Git & GitHub

## Características

- Filtros dinámicos
- Interfaz responsive
- Arquitectura frontend/backend
- Organización modular del proyecto

## Objetivo

Proyecto realizado como práctica de desarrollo Full Stack durante la formación en Global Academy.
